# `stagesRuleset()` extracts and filters specific set of rules for every cancer

`stagesRuleset()` extracts and filters specific set of rules for every
cancer

## Usage

``` r
stagesRules(edition, cancer, type)
```

## Arguments

- edition:

  A choice of "unspecified", "7th" and "8th".

- cancer:

  In character, the affected site, a choice of: "bladder", "breast",
  "colorectal", "lung", "melanoma", "oesophagus" and "prostate".

- type:

  A choice from "base", "clinical" or "pathological" stage rule.

## Value

`NULL`, called for its side effects.
